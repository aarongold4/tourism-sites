# tourism-sites
Build, audit and deploy pipeline for Aaron's tourism guides (petratourism.com, gizatourism.com, tbilisitourism.com, tashkenttourism.com, northmacedoniatourism.com). See CLAUDE.md.

Things Aaron may edit directly on GitHub (pencil icon → Commit): `sites/<domain>/site.json` (`ga4_id`) and `sites/<domain>/links.json` (`affiliate_ids` or individual URLs). Every commit redeploys automatically.
